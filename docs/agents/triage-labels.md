# Triage labels

These five canonical roles map directly to the labels in this repo's GitHub Issues.

| Skill role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | The maintainer needs to evaluate the issue. |
| `needs-info` | `needs-info` | The issue needs more information from its reporter. |
| `ready-for-agent` | `ready-for-agent` | The issue has enough detail for an agent to implement it. |
| `ready-for-human` | `ready-for-human` | The issue needs human implementation. |
| `wontfix` | `wontfix` | The maintainer does not plan to act on the issue. |

When a skill names a role, use its mapped GitHub label. Edit the GitHub label column if this repo later uses different names.
